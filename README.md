# WMC-Bridge-Plugin
![tip](https://img.shields.io/badge/python-3.10%2B-blue?logo=python&logoColor=white) ![tip](https://badgen.net/github/license/Hu-XiaoYan/WMC-Bridge-Plugin) ![tip](https://badgen.net/github/commits/Hu-XiaoYan/WMC-Bridge-Plugin) ![tip](https://badgen.net/github/last-commit/Hu-XiaoYan/WMC-Bridge-Plugin) ![tip](https://badgen.net/badge/Last-Test-Version/Alpha-0.1/orange)  
一个简单的Python插件, 可将国内主流非支持SMTC(SystemMediaTransportControls)的音乐播放器的播放信息映射到SMTC中, 并由其他应用读取(例如OBS的Tuna插件, 可以将SMTC信息映射到直播间)  
目前该项目处于测试状态, 暂时不会发包, 若有需要可以安装以下依赖(pillow, tomli, winsdk, win32api, requests)并运行run-ttk.py使用
